# Resonance

Local-first music player and automix engine.

## Run

```bash
git clone https://github.com/ar-shenoy/resonance.git
cd resonance
npx serve public
```

Open the URL shown in the terminal (usually `http://localhost:3000`).

## Features

- Local audio library (import / drag-and-drop)
- Playback with transport controls
- BPM / energy analysis
- Dual-deck automix
- Hot cues, loops, pitch
- Playlists, favorites, history, search
- Session export
- Offline-first; no account required
